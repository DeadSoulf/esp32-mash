ESP32 AutoMesh v0.3.11-dev — обновления через веб-панель шлюза

ШЛЮЗ (Web-OTA/):
  gateway-esp32c3-provisioner.bin      ESP32-C3 SuperMini 4MB
  gateway-esp32s3-zero-provisioner.bin Waveshare ESP32-S3-Zero 4MB

УЗЛЫ (Web-OTA/Nodes/):
  node-esp32c3-onoff_server.bin      ESP32-C3 SuperMini 4MB
  node-esp32s3-zero-onoff_server.bin Waveshare ESP32-S3-Zero 4MB

SHA256SUMS.txt в этой папке содержит контрольные суммы всех четырёх
файлов и относительные пути к ним.

ОБНОВЛЕНИЕ ШЛЮЗА:
1. Войдите на веб-панель шлюза.
2. В «Обновление прошивки шлюза» выберите файл gateway-*.bin для чипа.
3. Нажмите «Проверить и обновить». После перезагрузки проверьте версию.

ОБНОВЛЕНИЕ УЗЛА:
1. Шлюз и узел должны работать на 0.3.11-dev или более новой версии OTA1.
   Если узел старый и OTA1 отсутствует, сначала прошейте узел по USB.
2. В веб-панели шлюза откройте «Обновление выбранного Mesh-узла».
3. Выберите ОДИН доступный узел; проверьте тип C3/S3 и файл из Nodes.
4. Запустите обновление, дождитесь 100% и подтверждения проверки образа.
   Сеть передаёт данные по BLE Mesh, поэтому процедура может быть
   значительно дольше обычного обновления через Wi-Fi.
5. После перезагрузки узла убедитесь, что отображается новая версия.

БЕЗОПАСНОСТЬ:
- Не отправляйте бинарник шлюза узлу или узла шлюзу.
- Передача допускается только авторизованным администратором.
- Узел сверяет SHA-256, чип, тип приложения и OTA-образ до перезапуска.
- Изменения касаются только неактивного APP-раздела, без стирания NVS.
- При прерванной передаче старая прошивка продолжает работать.
- Протокол экспериментальный; проверяйте на одном тестовом узле.
- Массовая автоматическая OTA, резервный провиженер и принудительное
  переподключение Mesh здесь не реализованы.
