# Ручное обновление шлюза ESP32 через веб

Начиная с v0.3.6-dev веб-панель позволяет загрузить бинарную прошивку
приложения шлюза (не узла). Возможности:

- Только после входа администратора, в режиме подключения к роутеру.
- Две платформы: ESP32-C3 / ESP32-S3; заголовок образа проверяется
  на самом контроллере вместе с именем приложения.
- Проверка размера OTA-раздела, контрольной суммы приложения и
  дополнительная сверка с SHA-256 при указании хеша релиза.
- Запись в неактивный OTA app-раздел, переключение загрузки после
  проверки, перезагрузка по завершении ответа HTTP.
- Сохранение NVS (ключи администратора и Wi-Fi, Mesh, имена устройств).
- Загрузчик поддерживает откат. Новая версия подтверждает загрузку
  только после успешного запуска веб-сервера и получения IP роутера.

Используйте из ZIP релиза gateway-esp32c3-provisioner.bin или
gateway-esp32s3-provisioner.bin. Сначала проверьте модель шлюза,
указанную в разделе обновления.

Ограничения: Это обновление только шлюза, не узлов по BLE Mesh.
HTTP не обеспечивает конфиденциальность пароля и файла обновления.
В защищённой домашней сети риск ниже, но полноценная защита канала
требует HTTPS/VPN. Если шлюз ещё на старой версии без Web OTA, для
первого перехода нужен USB-установщик. Важно иметь резервную копию
полной Flash. Не выключать питание во время записи.

Если шлюз не получает IP после OTA, его загрузчик сможет откатить
новую версию при последующей перезагрузке. Если ранее установленная
разметка разделов отличается от OTA-разметки проекта, сначала нужен
контролируемый USB-переход; не загружайте чужие образы.
