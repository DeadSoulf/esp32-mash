# ESP32 AutoMesh

Экспериментальная сеть **Bluetooth Mesh на ESP32** с Wi-Fi веб-панелью шлюза, ручным подтверждением новых устройств и адресной командой **«Найти»** (быстрое мигание светодиода выбранного узла).

## Что уже реализовано

- ESP32-C3 (Flash 4 МБ): прошивки **gateway** и **node** на ESP-IDF 5.5.3.
- Веб-интерфейс шлюза с поиском Wi-Fi, настройкой подключения, списком Mesh-устройств и ручной регистрацией по OOB.
- Индикация состояния Mesh на ESP32-C3 SuperMini (GPIO8, active-low).
- Команда поиска выбранного зарегистрированного узла с миганием 15 секунд (прототип, необходим сквозной тест подтверждения/привязки).
- Начальный установщик для Windows: обнаружение SoC и Flash, проверка совместимости, полная резервная копия перед прошивкой, SHA-256 образов.
- ESP32-S3, Flash 4 МБ: собран вариант прошивки узла; для других моделей S3 назначение светодиода зависит от платы. Поддержка S3-шлюза и общий пакет установщика находятся в проверке.

## Ограничения

Адресное **OTA по Bluetooth Mesh** ещё не реализовано. Компиляция не подтверждает успешную работу всего Mesh; нужно протестировать регистрацию и команду «Найти» на нескольких физических платах. GPIO LED на разных платах отличается. Код и веб-интерфейс пока являются инженерным прототипом, не готовой системой для открытого интернета.

## Безопасность

**Не размещать в GitHub:** дампы Flash, Wi-Fi-пароли, Mesh/OOB-ключи, администраторские токены, персональные адреса и журналы с секретами. Резервные копии сохраняются **только локально** в `D:\AI\99_Archive\ESP32-AutoMesh-Private`.

Основная ветка — **main**; дополнительных веток не используем.

В исходниках используются примеры Espressif ESP-IDF. Сохранены уведомления об авторстве и лицензии исходных компонентов; перед коммерческим распространением необходима отдельная проверка лицензий и идентификатора производителя BLE Mesh.
