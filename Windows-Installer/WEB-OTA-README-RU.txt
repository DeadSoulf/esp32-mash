ESP32 AutoMesh — обновление ШЛЮЗА через веб-панель
Версия пакета: v0.3.10-dev

В папке:
  gateway-esp32c3-provisioner.bin      — ESP32-C3 SuperMini, 4 МБ Flash
  gateway-esp32s3-zero-provisioner.bin — Waveshare ESP32-S3-Zero, 4 МБ Flash
  SHA256SUMS.txt                       — SHA-256 для обоих образов

Как обновить:
1. Откройте веб-панель существующего шлюза и войдите в неё.
2. Проверьте чип шлюза в разделе «Обновление прошивки шлюза».
3. Выберите .bin из ЭТОЙ папки для соответствующего чипа.
4. При необходимости скопируйте SHA-256 в поле проверки.
5. Нажмите «Проверить и обновить шлюз» и дождитесь перезагрузки.
6. Проверьте версию 0.3.10-dev и идентификатор сборки в шапке панели.

ВАЖНО:
- Это приложение ШЛЮЗА для веб-OTA, не USB-комплект и не загрузчик.
- Обновление УЗЛОВ по BLE Mesh через веб пока НЕ поддерживается.
  Для обновления узла используйте Windows USB-установщик.
- Шлюз со старой прошивкой без веб-OTA обновляется через USB.
- OTA требует настроенного Wi-Fi и совместимой разметки OTA-разделов.
- Содержимое NVS (Wi-Fi, Mesh-ключи) при веб-OTA не стирается.
- Не выключайте питание до завершения загрузки и перезапуска.
- Никогда не используйте .bin от другого чипа.
- Перед обновлением сделайте резервную копию и сохраните её приватно.
