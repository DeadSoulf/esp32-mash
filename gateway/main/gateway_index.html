Первый запуск — создание администратора

Шлюз пока не подключён к домашней сети. Его Wi-Fi AutoMesh доступен без пароля. Настройку необходимо выполнить рядом с устройством: пока сеть открыта, любой поблизости может подключиться и попытаться стать первым администратором.

Ключ будет храниться в защищённом виде в памяти ESP32. После создания подключите шлюз к Wi-Fi роутеру.

Доступ к панели

Введите собственный ключ администратора. Для старого шлюза пока действует прежний ключ из USB-журнала, пока вы его не измените.

Настройки Wi-Fi шлюза

Поиск доступных сетей, выбор роутера и смена Wi-Fi подключения. Во время поиска связь Bluetooth Mesh может ненадолго замедлиться.

Выберите поиск, чтобы увидеть сети рядом со шлюзом.

После выбора другой Wi-Fi сети шлюз перезагрузится. Если подключение не удастся, прежние настройки автоматически восстановятся примерно через 45 секунд. Новый IP-адрес появится в USB-журнале.

Обновление прошивки шлюза через веб-панель

Загружается только приложение шлюза provisioner.bin, собранное именно для вашего ESP32-C3 или ESP32-S3. Не выбирайте архив ZIP, дамп Flash, прошивку узла или bootloader. Обновление ручное, выполняется в резервный OTA-раздел; Wi-Fi, имена устройств и Mesh-ключи в NVS не стираются.

Определение модели шлюза...

Обновление не запускалось.

После загрузки и проверки ESP32 перезагрузится. При неудачном запуске механизм загрузчика может откатить обновление. Сохраните резервную копию перед обновлением.

Обновление выбранного Mesh-узла

Выберите узел с поддержкой OTA1 и файл onoff_server.bin из Web-OTA/Nodes. Шлюз по BLE Mesh пересылает блоки с подтверждениями. Передача может быть длительной; не закрывайте вкладку до окончания. Другие узлы не обновляются.

Обновление не запускалось.

Для старого узла без OTA1 требуется одно начальное обновление по USB. Незавершённый OTA-образ не запускается, Mesh-ключи и NVS не удаляются.

Радиосвязь и индикация

Узлы получают контрольный запрос от шлюза. При ответе светодиод горит; если ответа нет 35 секунд — мигает. Шлюз работает по Wi-Fi для веб-панели, а ESP32 общаются друг с другом через BLE Mesh.
