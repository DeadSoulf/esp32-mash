# Сохранение и восстановление Bluetooth Mesh

## Почему устройства исчезали после выключения питания

В выпущенных ранее тестовых образах ESP32-C3 настройка `CONFIG_BLE_MESH_SETTINGS` была **отключена**. ESP-IDF поэтому не сохранял автоматически сетевые ключи, адреса и таблицу Provisioner. Дополнительная оперативная таблица шлюза не заменяла полноценное хранение Mesh-ключей.

Начиная с исходников v0.3.2-dev постоянное хранение включено **и на узле, и на шлюзе**. Имена зарегистрированных устройств сохраняются отдельно в NVS шлюза по UUID. Недоступные узлы остаются в списке со статусом «Нет связи», а если ключи SDK отсутствуют — «Нужна настройка Mesh».

## Порядок восстановления

1. Сохранить полные резервные копии Flash всех плат, не публиковать их.
2. Собрать и проверить **обе** прошивки с `CONFIG_BLE_MESH_SETTINGS=y`.
3. Установить проверенные образы на шлюз и узлы без стирания NVS; при изменении таблицы разделов применить безопасную стратегию переноса.
4. Если ранее зарегистрированные ESP32 не сохранили Mesh-ключи, повторить регистрацию вручную с индивидуальным OOB. Не использовать старые ключи от другого устройства.
5. Назвать узлы в веб-панели с помощью кнопки «Имя». После перезагрузки шлюза проверить сохранение имён и списка.
6. Нажать «Найти» на выбранном узле: панель должна дождаться подтверждения доставки, а индикатор узла — быстро мигать до 15 секунд; остальные не должны мигать.

Никогда не сбрасывать NVS ради восстановления интерфейса без резервной копии. Удаление записи из панели не удаляет Mesh-ключи из SDK. Для настоящего удаления устройства понадобится штатная процедура конфигурации/отзыва ключей.

## Контрольные проверки

- `CONFIG_BLE_MESH_SETTINGS=y` присутствует в итоговом `sdkconfig` шлюза и узла.
- В журнале шлюза есть количество восстановленных узлов из native Provisioner table.
- После перезапуска шлюза список сохраняется, но статус `online` выставляется только после нового ответа.
- Название сохраняется по UUID.
- Веб-кнопка «Найти» не объявляет успех до ACK от адресованного узла.
- Если Mesh ключи отсутствуют, ошибка видна пользователю и устройству требуется повторная регистрация.

**Статус:** это изменения исходного кода, требующие тестирования на двух платах. CI-сборка проверяет компиляцию, но не заменяет аппаратный тест.
