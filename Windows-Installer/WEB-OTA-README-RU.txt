ESP32 AutoMesh v0.3.13-dev — обновления через веб-панель шлюза

ШЛЮЗ (Web-OTA/):
  gateway-esp32c3-provisioner.bin      ESP32-C3 SuperMini 4MB
  gateway-esp32s3-zero-provisioner.bin Waveshare ESP32-S3-Zero 4MB

УЗЛЫ (Web-OTA/Nodes/):
  node-esp32c3-onoff_server.bin      ESP32-C3 SuperMini 4MB
  node-esp32s3-zero-onoff_server.bin Waveshare ESP32-S3-Zero 4MB

SHA256SUMS.txt в этой папке содержит контрольные суммы всех четырёх
файлов и относительные пути к ним.

ОБНОВЛЕНИЕ ЛЮБОГО УСТРОЙСТВА — ОДИН РАЗДЕЛ:
1. Откройте веб-панель шлюза и войдите.
2. Выберите ШЛЮЗ или ОДИН доступный узел с поддержкой OTA1.
3. Выберите полный ZIP релиза AutoMesh либо подходящий APP .bin
   из папки Web-OTA; панель автоматически выберет нужный файл из ZIP.
4. Браузер проверит чип C3/S3, роль, версию и вычислит SHA-256.
   Несовместимая прошивка не будет отправлена.
5. Нажмите «Обновить» ОДИН раз. Следите за прогрессом и дождитесь
   подтверждения проверки и перезапуска ESP32.

Дополнительные сведения:
- Для устаревших узлов без OTA1 нужна однократная прошивка по USB.
- Обновление узла через BLE Mesh медленнее Wi-Fi обновления шлюза.
- Если браузер не умеет распаковывать ZIP (deflate-raw), выберите .bin.
- NVS, настройки Wi-Fi и Mesh-ключи при OTA не очищаются.
- Нет автоматической массовой установки или смены шлюза.

БЕЗОПАСНОСТЬ:
- Не отправляйте бинарник шлюза узлу или узла шлюзу.
- Передача допускается только авторизованным администратором.
- Узел сверяет SHA-256, чип, тип приложения и OTA-образ до перезапуска.
- Изменения касаются только неактивного APP-раздела, без стирания NVS.
- При прерванной передаче старая прошивка продолжает работать.
- Протокол экспериментальный; проверяйте на одном тестовом узле.
- Массовая автоматическая OTA, резервный провиженер и принудительное
  переподключение Mesh здесь не реализованы.
