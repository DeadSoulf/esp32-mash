# Регистрация устройств без отдельного OOB-кода

Версия v0.3.5-dev: один пароль для входа в веб-панель шлюза и
для **разрешения** добавления найденной ESP32.

Порядок:
1. Войти в веб-панель ключом администратора.
2. В списке ожидания выбрать конкретную ESP32.
3. Нажать «Разрешить» и подтвердить действие.
4. Шлюз выполняет Bluetooth Mesh No-OOB provisioning, сохраняет
   устройство и конфигурирует его. Ввод OOB-кода отсутствует.

Никакого копирования или передачи пароля администратора на узел
не происходит. Пароль остаётся на шлюзе; он авторизует HTTP-операцию.
Mesh применяет режим No OOB и создаёт ключи сети обычным протоколом.
Для этого **не нужно** вводить пароль на узле.

Ограничение безопасности: режим No OOB **не защищает криптографически
от активной подмены устройства при регистрации**. Невозможно считать
пароль веб-панели доказательством физической подлинности удалённой
ESP32. Выполняйте добавление в контролируемой радиозоне, сверяйте
UUID/идентификатор и не подтверждайте неизвестные устройства.

Для ранее прошитых узлов с обязательным Static OOB потребуется
установить новую прошивку узла *без очистки NVS*. Ранее
зарегистрированные узлы должны продолжать работать без повторного
добавления. Если на шлюзе потерялись Mesh-ключи, осторожно выполните
повторную регистрацию по отдельной процедуре с резервной копией;
не стирайте NVS для обычного обновления.
