Доступ к панели

Ключ администратора напечатан шлюзом в USB-журнале при запуске. Wi-Fi пароль не является ключом администратора.

Настройки Wi-Fi шлюза

Поиск доступных сетей, выбор роутера и смена Wi-Fi подключения. Во время поиска связь Bluetooth Mesh может ненадолго замедлиться.

Выберите поиск, чтобы увидеть сети рядом со шлюзом.

После выбора другой Wi-Fi сети шлюз перезагрузится. Если подключение не удастся, прежние настройки автоматически восстановятся примерно через 45 секунд. Новый IP-адрес появится в USB-журнале.

Радиосвязь и индикация

Узлы получают контрольный запрос от шлюза. При ответе светодиод горит; если ответа нет 35 секунд — мигает. Шлюз работает по Wi-Fi для веб-панели, а ESP32 общаются друг с другом через BLE Mesh.
