AutoMesh — первичная установка прошивок ESP32 для Windows
Версия пакета: 0.3.4-dev

Поддерживаемые профили:
  ESP32-C3 SuperMini, Flash 4 MB (GPIO8, обычный active-low LED).
  ESP32-S3 с USB Serial/JTAG, Flash 4 MB (универсальный профиль;
            встроенный светодиод ОТКЛЮЧЁН до уточнения типа и GPIO конкретной платы).
Дополнительная PSRAM на S3 не обязательна, не используется приложением.

БЫСТРЫЙ ЗАПУСК
1. Подключите ESP32 к ПК через USB-кабель с поддержкой передачи данных.
2. Запустите Install-AutoMesh.cmd или AutoMesh-Installer.exe.
3. Установщик автоматически обнаружит USB COM-порты, определит тип ESP32,
   MAC и действительный размер Flash средствами esptool.
4. Программа подберёт отдельные совместимые образы для вашего чипа и Flash.
   Если совпадения нет — ОТКАЖЕТСЯ прошивать чужую сборку.
   Распиновку светодиода и функциональную роль чип автоматически НЕ определяет.
5. Если на плате уже был AutoMesh, роль определяется по резервной копии Flash.
   Для новой платы можно выбрать: узел (по умолчанию) или шлюз.
6. Перед записью программа проверяет SHA-256 файлов, подтверждение профиля,
   считывает ПОЛНУЮ резервную копию Flash и просит окончательное разрешение.
7. NVS по умолчанию сохраняется (вместе с Mesh-ключами, настройками).
   Очистка NVS выполняется только после отдельного явного подтверждения.
8. Записываются загрузчик, таблица разделов, OTA-метаданные и приложение.

КОМАНДЫ
  AutoMesh-Installer.exe --check
  AutoMesh-Installer.exe --port COM16 --check
  AutoMesh-Installer.exe --port COM16 --role node
  AutoMesh-Installer.exe --port COM16 --role gateway

--check НЕ изменяет содержимое Flash и не делает резервную копию.
Для установки необходимо ввести отдельные подтверждения.
AutoMesh-Installer.exe не требует установленного Python.
installer.py при запуске из исходника требует esptool + pyserial.

ВНИМАНИЕ
  ESP32-S3 выпускается с разным объёмом Flash (4/8/16 МБ), вариантом
  PSRAM, типом встроенного LED (обычный или адресный RGB) и GPIO.
  В комплект вошла отдельная компиляция ESP32-S3 с Flash 4 МБ.
  Для ESP32-S3 с 8/16 МБ нужны дополнительные профили и проверенные
  сборки с подходящей разметкой; данный установщик НЕ станет подменять их
  четырёхмегабайтной прошивкой.
  В режиме универсальной S3 сборки штатный индикатор сети/команда «Найти»
  по LED не работают без определения правильного вывода и типа светодиода.
  Bluetooth Mesh и веб-панель шлюза в прошивку включены.

  НЕ отключать питание/USB во время Flash-записи.
  Резервные копии сохраняются в %LOCALAPPDATA%\ESP32-AutoMesh\Backups.
  Они могут содержать Wi-Fi пароли и секретные Mesh-ключи.
  Не публикуйте их в GitHub или общем архиве с прошивками.
  Готовые образы проверены при сборке, но первая установка на ESP32-S3
  физически не проведена и не заменяет тестирование устройства.

  Не используйте Bluetooth Mesh web-панель из открытого интернета без
  дополнительно защищённого подключения. Веб-панель требует админ-токен.



ESP32-S3: универсальная прошивка для чипа ESP32-S3 с 4 МБ Flash.
Установщик умеет автоматически распознать S3 и подобрать отдельно
собранную прошивку шлюза или узла. Это не означает автоматическое
определение распиновки платы: встроенный LED для generic S3 отключён.
Если нужен сигнал мигания «Найти», необходимо уточнить модель платы
и тип/GPIO её светодиода, затем собрать соответствующий вариант.
Команда проверки без записи: AutoMesh-Installer.exe --self-test
Для проверки подключённой платы: AutoMesh-Installer.exe --port COM16 --check
ВНИМАНИЕ: доступен только профиль Flash 4 МБ. Не используйте его для
плат ESP32-S3 с Flash 8/16 МБ. Резервная копия обязательна.


НОВЫЙ ШЛЮЗ: при отсутствии сохранённого Wi-Fi устройство создаёт открытую
сеть AutoMesh-XXXXXX без пароля. Откройте http://192.168.4.1/ и задайте
собственный ключ администратора от 6 символов. Он хранится в NVS шлюза
как PBKDF2-хеш и переживает перезапуск. Для уже настроенных шлюзов
старый 32-символьный токен сохраняется до ручной смены в веб-панели.
Сеть без пароля небезопасна: настройте администраторский ключ и роутер
в контролируемом месте без посторонних поблизости.


Исправление v0.3.4-dev: неверный ключ администратора больше не вызывает
повторяющиеся запросы из браузера и блокировку HTTP 429. При 401 панель
удаляет неверный ключ и предлагает вход. При 429 показывает время
ожидания. Ключ администратора и настройки Mesh в NVS не удаляются.
